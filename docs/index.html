agent-cost-guard

A budget in front of any OpenAI-compatible endpoint.

An agent loop is unbounded by nature: it retries, it re-reads files, it calls tools in circles. This proxy puts a wall around it — a token budget, a spend budget, a round-trip cap and a latency ceiling — in front of any endpoint that speaks OpenAI.

View on GitHub npm README

What it does

Token budgetPer session, checked before every request.
Spend budgetPriced per model, in US dollars.
Round-trip capStops tool-call storms before they cost you.
Latency ceilingA slow upstream cannot stall the agent forever.
Spend reportPer model, per session, at /report.

Usage

Start the guardagent-cost-guard --upstream https://api.example.com/v1 --port 8791
Point the agent at itexport OPENAI_BASE_URL=http://127.0.0.1:8791/v1
Tag the sessionexport OPENAI_DEFAULT_HEADERS='{"x-session-id":"my-session"}'
Read the reportcurl localhost:8791/report?id=my-session

How it works

  1. The budget is checked before the upstream is called.
  2. Usage is recorded after the response, priced with the model table.
  3. Over the budget the proxy answers 429 or 402 instead of spending more.
